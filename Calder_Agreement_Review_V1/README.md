# Calder Agreement Review - Portable Edition v1.6.4

This folder contains the Calder application. Setup, local run modes (demo and Supabase), deployment, evaluation, and documentation are covered in the repository's main [README](../README.md).

Quick start in demo mode, from this folder with no `.env.local` (Node.js 22 and npm):

```bash
npm install
npm run dev
```

Then open `http://localhost:5173`.
